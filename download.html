Getting started

Up and running in 3 steps

No server setup. No browser extension. Just download, install, and enter your license key.

1

Download & install

Click the button for your operating system above. macOS: open the .dmg and drag ClimRisk to Applications. Windows: run the .exe installer. Linux: make the .AppImage executable and double-click.

2

Enter your license key

On first launch, you'll see the activation screen. Paste the license key from your purchase confirmation email. Click Activate License. The app validates against ClimRisk servers and unlocks your tier's features.

3

Run your first assessment

The dashboard loads automatically. Type any public company name in the New Assessment field. The engine scores physical risk, transition risk, and generates 3-scenario NPV impact projections in under 60 seconds.

4

Auto-updates

ClimRisk Desktop checks for updates silently in the background. When a new version is available, a prompt appears. Click Restart & Update — the latest models and NGFS scenarios install automatically.

Why Desktop

Built for institutional workflows

A native app means deeper integration with your workstation — file dialogs, PDF export, no browser tabs, no re-authentication.

Any public company

Assess any listed company worldwide using the /agent/assess ML engine — not limited to a pre-seeded list. Powered by NGFS Phase 4 and IPCC AR6 data.
